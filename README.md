# 우리 광장 (everyone-chat)

친구들끼리 쓰는 본디 스타일 비공개 채팅 웹. GitHub Pages + Supabase 무료 플랜으로 운영.

- 주소: https://everyone-chat.github.io
- 기능: 입장 코드, 닉네임·캐릭터·색 꾸미기, 친구 광장(상태·접속 표시), 실시간 공용 채팅(최근 200개 보관)

## 입장 코드 바꾸기

마스터: 나 탭 → 👑 멤버 관리 → "새 입장 코드" 입력 → 바꾸기 (supabase/007_invite_code.sql)

또는 
Supabase 대시보드 → SQL Editor에서 아래 한 줄 실행 (코드는 공개 저장소에 적지 말 것)

```sql
update private.settings set value = '새-코드' where key = 'invite_code';
```

이미 들어온 친구는 그대로 이용 가능하고, 새로 들어오는 사람만 새 코드가 필요함.

## 구조

| 파일 | 역할 |
|---|---|
| `supabase/setup.sql` | 테이블, 보안 정책(RLS), 입장 코드 검증 함수, 실시간 설정 |
| `src/config.ts` | Supabase 주소와 공개(publishable) 키 |
| `src/screens/` | 입장 / 광장 / 채팅 / 나 화면 |
| `.github/workflows/deploy.yml` | main에 올리면 자동 빌드·배포 |

## 무료 운영 참고

- Supabase 무료 프로젝트는 일정 기간 접속이 없으면 일시정지될 수 있음 → 대시보드에서 무료로 다시 켜면 됨
- 채팅은 최근 200개만 보관해서 DB 용량 걱정 없음
- 계정은 브라우저에 저장됨 → 브라우저 데이터 삭제·기기 변경 시 새로 입장

## 마스터 기능 (supabase/002_admin.sql)

| 기능 | 사용법 |
|---|---|
| 마스터 되기 | 입장 화면에 마스터 코드 입력, 또는 이미 들어왔다면 나 탭 → "마스터 코드 입력" |
| 내보내기 | 광장에서 친구 캐릭터 누르기 → "채팅방에서 내보내기" (두 번 눌러 확정) |
| 메시지 삭제 | 채팅에서 메시지 누르기 → "메시지 삭제" (내 메시지는 누구나, 남의 메시지는 마스터만) |
| 채팅 전체 삭제 | 채팅 탭 오른쪽 위 "🗑 전체 삭제" (마스터만, 두 번 눌러 확정) |
| 채팅방 나가기 | 나 탭 → "채팅방 나가기" (두 번 눌러 확정) |

마스터 코드 바꾸기: `update private.settings set value = '새-코드' where key = 'admin_code';`

## 사진 전송 (supabase/003_photos_clear.sql)

- 채팅 입력창 왼쪽 📷 버튼 → 사진 선택 → 보내기
- 비공개 저장소(chat-images)에 저장, 멤버만 볼 수 있음
- 올리기 전에 긴 변 1600px JPEG로 자동 축소 (무료 저장 용량 1GB 기준 수천 장)
- 메시지가 지워지면(개별 삭제, 마스터 전체 삭제, 200개 초과 자동 정리 모두) 사진 파일도 저장소에서 삭제됨 (supabase/004_image_cleanup.sql)
- 지워진 사진 목록은 서버가 기록하고, 접속 중인 멤버의 앱이 바로 실제 파일을 지움

## 친구 & 1:1 채팅 (supabase/005_friends_dm.sql)

- 공용 채팅방은 없어지고 친구끼리 1:1 대화만 있음
- 친구 추가: 나 탭 → 친구의 코드 입력 → 바로 서로 친구 (코드를 아는 사람만 추가 가능)
- 내 친구 코드: 처음엔 자동 6자리, 나 탭에서 원하는 코드로 바꾸기 (한글·영문·숫자·-·_ 2~16자, 중복 불가)
- 친구가 아니면 광장·채팅·프로필 어디에도 보이지 않음 (서버 보안 정책으로 차단)
- 친구 끊기: 둘의 대화와 사진도 함께 삭제
- 마스터: 나 탭 "멤버 관리"에서 전체 멤버를 보고 내보내기 가능, "내보낸 멤버"에서 다시 들이기 가능 (supabase/006_unban.sql). 남의 대화는 볼 수 없음

## 개인정보 보강 (supabase/008_privacy.sql)

마스터를 제외하면, 친구로 맺지 않은 사람끼리는 서로 사이트를 쓰는지조차 알 수 없음

| 경로 | 처리 |
|---|---|
| 프로필·광장·채팅·사진 | 서버 보안 정책으로 나와 내 친구 것만 내려줌 |
| 실시간 알림 | 친구 관계 알림은 당사자 본인 프로필 변경으로만 전달 (관계없는 사람에게 안 감) |
| 지운 사진 정리 목록 | 그 대화의 두 사람과 마스터에게만 보임 |
| 친구 코드 무작위 대입 | 10분에 10번 틀리면 10분간 잠금 |

## 캐릭터 (시트 PNG 파츠 조합)

- 사용자가 준 캐릭터 시트에서 파츠를 잘라 배경을 지우고, 같은 캔버스(420x640)에 위치를 맞춘 WebP 레이어로 저장 (public/parts, 약 1.5MB)
- 잘라내는 스크립트: tools/build.py (원본 시트 10장 필요)
- 조합: 성별 × 헤어 5 × 눈 5 × 표정 5 × (상의 5 + 하의 5 또는 원피스·세트 5) × 신발 5 × 모자 5 × 안경·소품 5
- 머리색·피부색 변경 가능 (머리·피부 레이어를 "기본색=흰색" 이미지로 만들어 곱하기 필터로 색칠). 옷·신발·모자는 원래 색만
- 상태가 자는 중·일하는 중·밥 먹는 중·쉬는 중·바쁜 중·씻는 중이면 행동 포즈 그림으로 바뀜 (포즈는 시트의 기본 헤어·옷 그대로, 머리색·피부색만 반영)
- 저장: profiles.emoji 칸에 `a3:...` 문자열 (예전 a1·a2 값은 자동 변환)

## 광장 = 내 방 (src/room/, src/screens/Plaza.tsx, supabase/009_rooms.sql)

- 광장이 곧 내 방: 내 방 안에 나와 친구들이 함께 서 있음 (친구 자리는 끌어서 옮기면 저장)
- "방 꾸미기" 버튼으로 편집 모드. 고정 원근 2D 방 (정면 벽, 양쪽 벽, 바닥, 오른쪽 창문)
- 벽지 5종(기본 핑크·크림·스트라이프·하트·체크) + 색, 바닥 5종(우드 밝은·진한·화이트 우드·헤링본·타일) + 색
- 가구: 침대·소파·책상·의자·수납장·러그는 시트 PNG (색조 6가지), 화분·조명은 직접 그린 3종 / 좌우 반전 / 삭제 / 최대 30개
- 드래그로 이동. 앞쪽으로 올수록 커지고, 앞에 있는 가구·캐릭터가 뒤를 가림 (러그는 항상 바닥)
- 내 캐릭터가 방 안에 표시되고 같이 드래그 가능 (가구와 같은 cm 비율)
- 바뀌면 1초 뒤 자동 저장 (rooms 테이블, 본인만 읽기·쓰기), 재접속 시 그대로 복원
